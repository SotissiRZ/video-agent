# Sirago — publicité

> Crée une vidéo verticale de 30 secondes pour promouvoir Sirago auprès des chauffeurs au Burkina Faso.

## Concept

- **Idée** : Montrer comment Sirago simplifie le quotidien pour les chauffeurs au Burkina Faso.
- **Angle** : Du problème du quotidien à la solution, en quelques secondes.
- **Ton** : Énergique, direct et positif
- **Message clé** : Sirago, pensé pour les chauffeurs.
- **Appel à l’action** : Essayez Sirago dès aujourd'hui
- **Signature** : Simple. Rapide. Fiable.
